# Aprendizaje de Idiomas

Aplicación web sencilla creada con React y Vite que ofrece tres secciones de estudio: Gramática, Lectura y Vocabulario.

Cada tema presenta un resumen, una explicación corta, un ejemplo práctico y pasos sugeridos para practicarlo.

## Requisitos previos

- Node.js 18 o superior
- npm 9 o superior

## Scripts disponibles

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

1. `npm run dev` inicia el entorno de desarrollo en `http://localhost:5173`.
2. `npm run build` genera los archivos optimizados de producción en la carpeta `dist`.
3. `npm run preview` sirve la versión generada para verificar la compilación.
4. `npm run lint` ejecuta ESLint sobre el proyecto.

## Cómo empezar

```bash
npm install
npm run dev
```

El comando `npm run dev` levanta el servidor en `http://localhost:5173`.

## Despliegue

1. Ejecuta `npm run build` para generar la carpeta `dist` lista para producción.
2. Publica la carpeta generada en el servicio de tu preferencia (por ejemplo, GitHub Pages, Netlify o Vercel).
